Help & Shortcuts

Writing

  • New — start a blank document
  • Insert Header (Ctrl+T) — adds a Name / Date / Class block at the top
  • Insert Word Count (Ctrl+Shift+C) — adds the current word count at the end
  • Special Characters — click to insert accented letters and symbols
  • Spelling is checked by your browser's built-in spellchecker (red underline)

Saving, Opening & Printing

  • Save (Ctrl+S) — saves to the same file, or asks where to save the first time
  • Save As (Ctrl+Shift+S) — always asks where to save a new copy
  • Open (Ctrl+Shift+O) — opens a .txt file from disk or USB drive
  • Print (Ctrl+P) — prints cleanly, without the toolbar
  • Your work is auto-saved in the browser as you type, and offered back to you if the page is closed or crashes before you save

Display

  • A− / A+ (Ctrl − / Ctrl +) — change text size, Ctrl 0 resets it
  • Line− / Line+ — change line spacing
  • Theme — switch between light and dark
  • Fullscreen — hide the browser chrome for a distraction-free view

Speech

  • Read Aloud — reads the selected text, or the whole document if nothing is selected. Click again to pause/resume.
  • Dictate — turns on the microphone and types what you say at the cursor. Click again to stop. Requires microphone access and an internet connection.

Special Characters

Click a character to insert it at your cursor.
